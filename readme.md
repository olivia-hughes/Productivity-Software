## Program's Purpose

Bored with what was on the market, I decided that the only way I could get my hands on the ideal productivity software that truly met my needs was to make it myself. Aside from creating a product that I would be happy to use myself rather than another simple 'to-do' program, this program's purpose is also to build upon my knowledge of springboot, maven, mySQL, and other such tools and libraries, as well as to also gain confidence in working independently and practice mindful coding. 

Considering this, I am also using this project as experience using industry-wide cautionary methods when building programs, such as using branches, documenting, comments that make code simple, clear and consistent formatting across all files of code, and most important of all, implementing security features. 

I have made my project public so that anyone who views this can give helpful feedback to me on how and where I can improve.

## User Manual
### How to start
First, please clone this repository to an IDE of your choice. I will be using VSCode. 

In a new terminal, please ensure that you have productivity-app as the source (if not, use `cd productivity-app`). 
From this fresh terminal, please run `.\mvnw.cmd spring-boot:run` - this will start our springboot application. 
If successful, you will see something along the lines of `Started ProductivityAppApplication` in the last line. Please contact me if you find an issue such as `"Communications link failure"`, `"Access denied for user"`, or `"Unknown database 'productivitydb'"`. When our application starts, Hibernate should initialise.
